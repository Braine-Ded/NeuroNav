->> Features
-> Interactive Sensory Map

Map-based interface displaying local businesses and public spaces as pins
Real-time filtering by sensory tags:

Sound — Quiet / Low-hum / Loud / Sudden Noises
Lighting — Natural Light / Dim / Bright / Flickering
Crowd Level — Empty / Spaced-out / Crowded
Scent — Fragrance-free / Strong Scents


Instant map updates on filter change — no page reloads

-> Crowdsourced Reporting System

Submit sensory reports for any location when logged in
Time-stamped reports so users know how recent the data is
"Confirm still true" button for community validation of existing reports

-> Real-Time Dashboard

Currently Calm — shows nearby low-sensory locations based on recent check-ins


-> Tech Stack
Fronted:  HTML, JS, CSS
Map: Leaflet.js
Backend Node.js + ExpressJS
Database: Postgres
Auth: JWT
